# PC 사용자 평가 자료 C2와 실행 참조 수정 — 2026-11-06

## 변경 이유

이전 참가자가 공유 요약의 ‘두 가지 가상 놀이’만으로는 어떤 놀이인지 알기 어렵다고 답했다. 실제 제품 기능을 추가하는 대신 평가 자료 C의 모호한 설명을 고쳤다. A/B의 고정 비교 자료와 이전 사용자 응답은 보존했다.

C2는 그림책 보기와 블록 쌓기 중 블록을 선택해 두 개를 포갠 **합성 관찰**을 제시한다. 다음에 전달할 내용은 선택한 놀이·아이 반응·어려움이며, 기존 공유 기록에 답장하도록 안내한다. 치료 강도·횟수·처방을 제시하지 않으며 사진·영상을 준비 완료된 첨부로 꾸미지 않는다.

## 변경 파일

- `tests/local-p0-study-fixture.mjs`: C 요약과 자료 버전 주석. 고정 baseline과 생성 흐름은 그대로 유지.
- `docs/p0-user-validation.md`: C2 요약, PC 평가 범위, 이전 C1 응답과의 구분.
- `tests/local-p0-study-browser.mjs`: 소스 확인 목록의 `local-p0-study-fixture.test.mjs`를 실제 이름인 `local-p0-study-fixture.integration.mjs`로 수정.

세 번째 변경은 앞선 GitHub 게시 준비에서 DB fixture 검사를 분리한 뒤 남아 있던 참조 누락이다. 새 실행이 소스 확인 단계에서 실패한 것을 발견하고 수정했다. 실패는 성공 결과로 합산하지 않았다. 제품 화면·API·인증·저장 정책은 변경하지 않았다.

브라우저 실행 `866adddd-9389-4a23-b79d-1ca6c7d7c1fd`는 오류·예상 밖 요청 0, 정상 정리 완료다. 548개 파일의 시작/종료/현재 지문은 `67840f2f8d4e1932f34b09f87dd17cec954178e89293f51d578d2738ef5145a7`로 일치했고, 실제 당일 사전 준비 판정은 true였다. 소유 프로세스 2개와 포트 6개의 종료도 별도로 확인했다. C2 모바일 캡처에서 전체 요약·활동 안내·인용 답장 접근을 직접 확인했다.

이 지문은 로컬 검사 환경의 소스 묶음이다. 공개 사본에서 개인 경로·로컬 결과 링크를 일반화하면 문서 지문은 달라지므로 새 환경에서는 자체 사전검사를 실행한다. 소스 지문이 다른 과거 결과를 재사용하지 않는다.

## 남은 평가

실제 아이폰은 사용자의 이번 요청에 따라 평가 시작 조건에서 제외한다. PC 모바일 검사와 GitHub 게시의 완료는 [게시 기록](github-release-20261106.md)에 있다.

현재 C2의 사람 이해도, 동일 조건의 A/B 작성 시간·실제 이동 수는 미수집이다. 기존 C1 의견을 C2 성공으로 바꾸거나 AI 조작 시간을 사람의 시간으로 기록하지 않는다. 직접 참여 여부가 확인되기 전에는 제한 시간이 있는 사람 평가 서버를 시작하지 않는다. 다음 단계는 준비된 C2를 읽은 사용자의 설명과 같은 조건에서의 A/B 조작 관측이다.
