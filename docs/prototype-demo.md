# Carebridge 프로토타입 시연 안내

2026-11-16 기준 목표는 PC·모바일에서 대화, 첨부, 기록, 보호자 공유와 AI 보조 흐름을 자연스럽게 시연하는 것입니다. 운영 인프라, 실제 아동 자료 접수와 장기 보관은 이번 범위에 포함하지 않습니다.

## 실행과 종료

**실제 홈 AI를 사용하려면 `Carebridge-OpenAI.cmd`를 실행합니다.** PowerShell 7의 가려진 입력란에 OpenAI 키를 직접 입력하면 새 로컬 주소와 시연 계정이 표시됩니다. 홈의 AI 대화와 기록 요약은 실제 OpenAI를 사용합니다. 키는 이번 서버 프로세스에서만 사용하며 파일·브라우저·URL에 저장하지 않습니다. 키가 없거나 요청이 실패해도 예시 응답으로 바꾸지 않습니다.

아래 `Carebridge-Prototype.cmd`는 키 없이 사용하는 **오프라인 예시 모드**입니다. 두 실행기는 같은 UI·첨부·공유 기능을 사용하고 별도의 가상 세션을 만듭니다. 이미 열린 예시 서버의 탭을 새로고침하는 것으로 실제 AI 모드가 되지는 않습니다. 새 실행기에 표시된 주소를 사용하세요.

1. 저장소의 `Carebridge-Prototype.cmd`를 더블클릭합니다. 터미널에서는 `npm run prototype`을 사용할 수 있습니다.
2. 브라우저가 열리면 터미널에 표시된 **치료사 시연 계정**으로 로그인합니다. 자동으로 열리지 않으면 표시된 로컬 주소를 직접 입력합니다.
3. 창을 열어 두고 시연합니다. 기본 실행기에 별도의 자동 종료 타이머는 없습니다. 계정을 다시 보려면 터미널에 `accounts`를 입력합니다.
4. 종료하려면 터미널에서 `q` + Enter 또는 Ctrl+C를 누릅니다. 다음 실행은 새로운 계정·가상 자료로 시작합니다.

이 PC에 설치된 Node.js 24와 프로젝트 의존성을 사용합니다. 다른 PC에 처음 설치할 때만 저장소에서 `npm ci --ignore-scripts`, `npm --prefix server ci --ignore-scripts`를 실행합니다. 로그인은 기존 인증 흐름을 사용하며 시연 계정은 파일이나 URL에 저장하지 않습니다.

이미 내용이 있는 항목은 기본 선택하지 않습니다. AI 초안으로 바꾸려면 변경 전후를 확인하고 교체에 동의해야 합니다. 사진·영상 첨부와 활동 답변은 서로 다른 계정에서도 확인할 수 있습니다. 한 브라우저에서 역할을 바꿀 때는 로그아웃 후 다른 시연 계정으로 로그인합니다.

홈 상단의 **AI 도우미**도 바로 사용할 수 있습니다. 연결된 아이가 한 명이면 해당 아이의 정보를 확인한 뒤 열고, 여러 명인데 아직 선택하지 않았다면 먼저 아이를 선택합니다. 창 상단의 ‘연결된 아이’를 확인하세요. ‘기록 요약’에서 선택한 저장 기록의 활동·반응을 실제 로컬 API로 불러옵니다. 자유 대화가 아이의 기록 전체를 자동으로 읽는 방식은 아닙니다.

## AI와 저장 범위

- 실제 홈 AI 실행기(`Carebridge-OpenAI.cmd`)는 홈 자유 대화와 선택한 기록 요약을 OpenAI로 처리합니다. 입력 질문·최근 AI 대화, 또는 사용자가 확인한 기록의 활동·반응 두 항목만 보냅니다. 전체 아동 기록·내부 메모·첨부 파일을 자동 전송하지 않습니다. 화면에 **OpenAI 사용 · 가상 자료 전용**이 표시됩니다.
- 실제 실행기는 대화 20회와 기록 요약 20회까지 요청하며 실패도 한도에 포함합니다. 자동 재시도·예시 응답 대체는 없습니다. AI 초안은 검토 후 직접 적용·저장해야 합니다. `q`로 종료하면 서버·가상 자료와 키를 사용하던 프로세스가 종료됩니다.
- 이번 홈 AI 변경에서는 녹음 정리의 제공 샘플 예시 모드를 유지합니다. 녹음 화면에 별도로 예시임을 표시하며 홈 대화가 실제 AI라는 이유로 녹음도 실제 처리했다고 표시하지 않습니다.
- 기본 프로토타입의 AI 대화·요약·녹음 분석은 화면에 표시된 **시연용 예시**입니다. 임의 녹음을 새로 전사하거나 외부 AI를 호출하지 않습니다.
- 실제 OpenAI 연결 기능과 가상 음성 검증 결과는 [AI 연결 문서](ai-assistant.md)에 별도로 있습니다. 예시 모드를 실제 모델 응답이라고 소개하지 않습니다.
- 메시지·기록·공유·활동 답변은 실제 로컬 API와 메모리 DB를 사용합니다. 브라우저 새로고침만으로 사라지지 않으며 서버를 종료하면 초기화됩니다.
- 첨부 샘플의 준비 상태는 프로토타입 전용 처리이며, 전송·권한·비공개 파일 조회는 기존 서비스를 사용합니다. 일반 실행기나 실제 AI 실행기의 권한·첨부 정책을 바꾸지 않습니다.

## 재검증

```sh
node --test tests/prototype-cli.test.mjs server/tests/prototype-ai-fixtures.test.mjs server/tests/prototype-sandbox.test.mjs
npm run test:prototype:browser
```

브라우저 검증에는 기존 프로젝트 검사와 동일하게 `PLAYWRIGHT_MODULE`과 `STUDY_CHROMIUM_EXECUTABLE`을 지정합니다. 실제 Chrome의 PC·모바일 크기에서 새 가상 세션을 만들고 종료 후 정리합니다. 상세 결과는 Git에 포함하지 않는 `test-results/`에 남습니다.

실제 모드의 오프라인 연결 검사는 `npm run test:prototype:home-ai`입니다. OpenAI 응답 모양을 가진 시험 provider로 브라우저→인증 API→데이터 흐름을 확인하며 실제 모델 호출 증거는 아닙니다. 실제 모델 검증은 PowerShell 7에서 `scripts/start-prototype-openai.ps1 -VerifyHome`을 실행해 키를 입력합니다. 제공된 새 가상 기록만 사용해 질문 1회·요약 1회(최대 두 요청)를 보내고 PC 1440px·모바일 390/320px를 확인합니다. 브라우저 결과와 HTTP 호출 수·상태만 안전한 보고서에 남기며 검증 후 시연 서버를 유지합니다. 실패 시 자동 재실행하지 않습니다. 검증 중 `q`로 종료하면 다음 호출을 중단하고 시험 브라우저와 세션을 정리합니다.
