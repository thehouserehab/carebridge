## 대화창 개선의 확인 범위

현재 `local-api/app.js`의 `fitChatViewport()`는 상단 화면과 대화 안내·입력·첨부 영역 높이를 화면 높이에서 차감하고, 대화 목록을 최소 160px까지 줄인다. 연결 후 인라인 높이를 적용하므로 CSS 높이만 바꿔서는 해결되지 않는다. 목록 폭은 기본 콘텐츠 최대 폭과 고정 290px 대화 목록 열의 영향을 받는다.

참가자가 말한 영역이 대화 목록·메시지 입력칸·활동 입력창 중 어디인지 추가 확인 중이다. 사용자 창의 화면 확인은 Windows 도구가 현재 URL을 판별하지 못해 중단했다. 별도 소유한 가상 서버·브라우저의 재현 결과를 참가자 화면 직접 관찰로 표현하지 않는다.

평가 세션 종료 확인 전에는 해당 버전의 제품 파일을 수정하지 않는다. 후속 수정에서는 PC 읽기·작성 공간을 확인하고, 모바일 입력 접근성·읽던 위치·미전송 내용 보존을 함께 검증한다.
